## Method

- **Data:** MUSDB18 test split, 7-second excerpts (Zenodo record 3270814, research/non-commercial licence). 6 tracks: Al James - Schoolboy Facination, AM Contra - Heart Peripheral, Angels In Amplifiers - I'm Alright, Arise - Run Run Run, Ben Carrigan - We'll Talk About It All Tonight, BKS - Bulldozer.
- **Code path:** `engine.separate()`, the same function the app calls. Output is WAV.
- **SDR:** MDX-challenge global SDR `10·log10(Σs² / Σ(s−ŝ)²)`, median across tracks (higher is better). Tracks whose reference stem is silent in the excerpt are excluded for that stem (n shows how many counted).
- **Leakage:** least-squares projection of the estimate onto the true target and the true interferer; interferer level relative to target in dB (lower is better). For *vocals* it is instrument bleed; for *accompaniment* it is vocal bleed.
- **Speed:** wall-clock seconds per minute of audio (median), including model inference and saving; the first-time model load is excluded by a warm-up.
- **GPU memory:** peak PyTorch tensor allocation during the job (`torch.cuda.max_memory_allocated`). The process also holds the CUDA context and allocator cache, so `nvidia-smi` shows roughly 1–2 GB more.

## Notes

- **Speed finding:** BS-RoFormer *fast* (overlap 2) scores within 0.06 dB of *best* (overlap 8) on vocals and within 0.07 dB on accompaniment, while running 2.8× faster. The app's default was changed from *balanced* to *fast* on this evidence.
- Seconds per minute are inflated on 7-second clips, because each clip is padded to at least one full model chunk. On a full 4.5-minute song the measured best-mode rate was about 2.4 s per second of audio.

- 7-second excerpts are short; full-song SDR is typically 0.5–1 dB higher because models use more context.
- Thresholds sit 2–4 dB below published full-length MUSDB18 scores to allow for the short excerpts and the simplified SDR. A failure means a real regression, not noise.
- Results are objective only; no listening test was used as an acceptance criterion.
